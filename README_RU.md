# eBay Market & Price Intelligence Scraper

[🇬🇧 Read in English](README.md)

---

Высокопроизводительный асинхронный скрейпер для мониторинга рынка, сбора цен и анализа товарных позиций маркетплейса eBay в реальном времени.

Проект спроектирован для надежного сбора данных в условиях агрессивного антифрода и защиты WAF (Akamai Edge) без использования дорогостоящих платных прокси.

### Ключевые архитектурные решения:
- **Обход Akamai Bot Manager:** Полная эмуляция человеческого поведения (Human Cadence): фоновые сессии через системный Chrome, плавный прогрессивный скроллинг страницы для генерации сенсорных событий, автоматический обход баннеров GDPR Cookie.
- **Универсальный парсер верстки:** Поддержка как классической структуры каталога (`.s-item`), так и обновленной A/B-верстки eBay (`.s-card`).
- **Двухформатный экспорт:** Автоматическая валидация и сохранение результатов в структурированные форматы `.csv` и `.json`.
- **Гибкая конфигурация:** Поддержка как прямых поисковых запросов, так и комплексных ссылок с выставленными фильтрами через `.env`.

### Стек технологий:
- **Python 3.12**
- **Playwright** (управление браузерным движком)
- **BeautifulSoup4** (высокоскоростной парсинг DOM-дерева)
- **python-dotenv** (изоляция конфигурации)
